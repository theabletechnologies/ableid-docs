Общие методы

Методы, не привязанные к конкретному продукту (AbleID, P2P, Pay). Не требуют сессию и не отправляют вебхуки — ответ приходит синхронно в теле HTTP-ответа.

Авторизация — пара projectId + secret в теле запроса, как и в остальных методах.

Проверка согласия OneID​

[POST] https://{domain}/check/check_oneid - URL для отправки запроса

Возвращает true или false — разрешена ли передача персональных данных по указанному ПИНФЛ в системе OneID.

Тело запроса​

{
  "projectId": "yDkeHoHWXVqQ9M_URZUtb",
  "secret": "y1iPwmpVmxOe4RFGvUoVHmPmlQ0nY5",
  "pinfl": "12345678901234",
  "lang": "ru"
}

Описание полей:

ПолеТипОписаниеОбязательноеПример
projectIdstringID проекта AbleIDДа"yDkeHoHWXVqQ9M_URZUtb"
secretstringСекретный ключ проектаДа"y1iPwmpVmxOe4RFGvUoVHmPmlQ0nY5"
pinflstringПИНФЛ (ровно 14 цифр)Да"12345678901234"
langstring (enum: ru, en, uz, oz)Язык сообщений ответаНет"ru"

Ответы​

Успешный ответ: 201​

{
  "statusCode": 200,
  "type": "SUCCESS",
  "message": "Успешно",
  "data": {
    "allowed": true
  }
}

Описание полей:

ПолеТипОписаниеОбязательноеПример
allowedbooleanРазрешена ли передача персональных данных в OneIDДаtrue

Ошибка: 400​

{
  "statusCode": 10103,
  "type": "FACE_INCORRECT_PINFL",
  "data": null,
  "message": "Некорректный ПИНФЛ"
}

Ошибка: 404​

{
  "statusCode": 10202,
  "type": "FACE_PROJECT_NOT_FOUND",
  "data": null,
  "message": "Проект не найден"
}
